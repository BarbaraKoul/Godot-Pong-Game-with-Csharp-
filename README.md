# Pong Game in Godot Engine with C#
<img width="1155" height="651" alt="Pong Game Screenshot" src="https://github.com/user-attachments/assets/a0f1cd69-0dc6-49e2-970a-376c8df04b21" />

As the coordinator of the IEEE NTUA SB game development team in the CS Chapter, I developed the first game for our meetings, the classic Pong, with C#.

## Features and Gameplay
- **Left paddle (Player 1):** It moves via the Arrow keys (keyboard)
- **Right paddle (Player 2):** It is controlled by an AI, meaning that it moves automatically towards the ball. 
- **Game Over:** If one player reaches 10 points, then there is a "Play Again" button and the game restarts.

## How to Run/Play the game

- Clone the Repository: ```bash git clone <https://github.com/BarbaraKoul/Godot-Pong-Game-with-Csharp->```
- Open **Godot Engine** and click **Import**
- Navigate to the cloned directory and select the ```project.godot``` file
- Press **F5** to run the game or export it for your OS!
